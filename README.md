# Portfolio: Fayaz H. Sahito
Static site, no build step. Works on GitHub Pages as-is.

1. Create a public repo named `YOUR-GITHUB.github.io`.
2. Upload every file in this folder to the repo root.
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Live at `https://YOUR-GITHUB.github.io` within a minute or two.
